# Nasir's WhatsApp Bot

24/7 AI Assistant that acts as Muhammad Nasir's digital twin.

## Features
- 24/7 operation on Render
- One-time WhatsApp linking
- AI responses in English/Urdu/Roman Urdu
- Admin-only controls
- Auto-reconnect

## Setup
1. Create database table using database.sql
2. Deploy to Render with environment variables
3. Link WhatsApp using Termux (once)
4. Bot runs automatically
